# Dashboard Business Intelligence

Project dashboard Business Intelligence untuk menyajikan data secara visual dan mudah dipahami. Dashboard ini digunakan untuk membantu melihat informasi dan pola data melalui visualisasi yang interaktif.

# Fitur

- Menampilkan data dalam bentuk visualisasi
- Menyajikan informasi melalui dashboard
- Analisis data melalui visualisasi
- Menampilkan grafik dan indikator data
- Penyajian data yang lebih mudah dipahami

# Tools & Teknologi

- Microsoft Power BI
- Microsoft Excel

# Cara Menjalankan

1. Clone repositori ini
2. Buka file project dashboard
3. Pastikan data yang digunakan tersedia
4. Buka dashboard menggunakan Microsoft Power BI
5. Lihat dan gunakan visualisasi data yang tersedia

## Hasil

Dashboard menghasilkan penyajian data secara visual sehingga informasi dan pola pada data dapat lebih mudah dipahami dan dianalisis.
